# Система для розыгрыша призов

Консольное приложение на Node.js для проведения случайных розыгрышей с визуализацией «колеса фортуны», ведением истории и поддержкой файлов CSV/JSON.

## Установка и запуск

1. Убедитесь, что установлен Node.js (версия 14 или выше).
2. Скопируйте проект в удобную папку.
3. Откройте терминал в папке проекта и установите зависимости:
   ```bash
   npm install
Запустите приложение:

bash
npm start
или

bash
node index.js
Использование
После запуска появится интерактивное меню с тремя пунктами:

🎲 Запустить розыгрыш — потребует указать путь к файлу с участниками. После загрузки запускается анимация и объявляется победитель. Результат сохраняется в data/history.json.

📜 Просмотреть историю — выводит список всех прошедших розыгрышей с датой, временем, количеством участников и именем победителя.

🚪 Выход — завершает работу программы.

Форматы файлов участников
Поддерживаются два формата: CSV и JSON.

CSV
Файл должен содержать заголовки id, name, contact. Пример:

csv
id,name,contact
1,Иван Петров,ivan@example.com
2,Мария Смирнова,maria@mail.ru
Если поля отсутствуют, система попытается их восстановить: id будет присвоен автоматически, name – "Участник N", contact – "не указан".

JSON
Файл должен содержать массив объектов с полями id, name, contact. Пример:

json
[
  { "id": 1, "name": "Иван Петров", "contact": "ivan@example.com" },
  { "id": 2, "name": "Мария Смирнова", "contact": "maria@mail.ru" }
]


Файл истории
История автоматически сохраняется в data/history.json. Каждая запись содержит:

date и time — дата и время розыгрыша;

participantsCount — количество участников;

participants — копия списка участников;

winner — информация о победителе.



Обработка ошибок

Приложение обрабатывает следующие ситуации:

Файл не найден — сообщение об ошибке и возврат в меню.

Некорректный формат файла (не CSV/JSON или нарушена структура) — вывод ошибки.

Пустой список участников — сообщение, что розыгрыш невозможен.

Ошибки ввода — валидация непустого пути.


Цветной вывод помогает быстро отличать информационные сообщения (синий), успешные операции (зелёный) и ошибки (красный).
